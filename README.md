# 圣经脉络

一个帮助中文读者深入理解圣经66卷书的静态网站。每卷导读包含核心主题、简明摘要、理解重点与实际生活应用，并提供新旧约概览、搜索和分类筛选。

“逐章研读”覆盖圣经66卷、1,189章，按书卷分文件载入，以便在手机和电脑上快速查阅。内容包括经文概览、结构、历史文化背景、神学信息、交叉经文与生活应用。

## 内容来源与使用提醒

逐章内容改编自 Eliran Wong 的 [Bible Chapter Summaries](https://github.com/eliranwong/BibleChapterSummaries)，依 [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/) 授权；详细说明见 [CONTENT_LICENSE.md](CONTENT_LICENSE.md)。

这些材料是辅助研读，不是圣经正文，也不应被视为无误的权威解释。请把内容与经文上下文、教会群体及可靠释经资料互相核对；涉及存在分歧的解释时，应保留辨别空间。

## GitHub Pages

将本仓库设为公开仓库后，在 **Settings → Pages** 中选择 **Deploy from a branch**，分支选择 `main`，目录选择 `/(root)`。保存后，网站通常会发布到：

`https://<你的用户名>.github.io/<仓库名>/`

无需构建步骤或外部依赖。
