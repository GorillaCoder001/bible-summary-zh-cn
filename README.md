# 圣经脉络

一个帮助中文读者深入理解圣经66卷书的静态网站。每卷导读包含核心主题、简明摘要、理解重点与实际生活应用，并提供新旧约概览、搜索和分类筛选。

“逐章研读”收录由既有研读文档整理而成的详细笔记，目前覆盖：创世记50章、马太福音27章（原文档暂缺第5章）、马可福音16章和路加福音第1章。后续可继续补充其他章节。

## GitHub Pages

将本仓库设为公开仓库后，在 **Settings → Pages** 中选择 **Deploy from a branch**，分支选择 `main`，目录选择 `/(root)`。保存后，网站通常会发布到：

`https://<你的用户名>.github.io/<仓库名>/`

无需构建步骤或外部依赖。
